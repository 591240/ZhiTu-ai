# 9 - 开发运行指南

> 配套文档：本指南说明「知途 AI 旅行」小程序前端 + 后端的本地运行与联调方式。设计稿见 `UI导出/`，UI 落地规范见 `docs/8`。

---

## 一、环境要求

| 层 | 要求 |
| :--- | :--- |
| 前端 | 微信开发者工具（稳定版）、支持游客/测试号预览 |
| 后端 | Python 3.13+、pip、可联网安装依赖 |
| 数据库 | 默认 SQLite（零配置）；生产可切 MySQL（`DATABASE_URL`） |
| 缓存 | Redis 可选（未配置时限流用内存兜底） |
| AI | 可选 LLM API Key；无 Key 时后端用内置示例生成器 |

---

## 二、前端运行（Mock 优先）

前端 `miniprogram/config/env.js` 关键开关：

```js
const env = {
  APP_NAME: '知途 AI 旅行',
  USE_MOCK: true,        // true=本地示例数据，无需后端
  BASE_URL: 'https://api.banyou.com/api',
  WX_APP_ID: '',
  DAILY_PLAN_LIMIT: 3
}
```

**零后端预览步骤**
1. 微信开发者工具 → 导入项目 → 选 `miniprogram/`
2. AppID 选「测试号」（项目已内置 `touristappid`）
3. 编译 → 模拟器/真机预览

`utils/mock.js` 提供完整示例数据（杭州/成都行程、模板广场、问答库），`request.js` 在 `USE_MOCK=true` 时直接走本地，并模拟 280ms 网络延迟。

---

## 三、后端运行

```bash
cd server
python -m venv venv
venv\Scripts\pip install -r requirements.txt
cp .env.example .env
# 可选：填写 WX_APP_ID / LLM_API_KEY / DATABASE_URL
venv\Scripts\uvicorn app.main:app --port 8000
```

启动后：
- `http://127.0.0.1:8000/` → 健康检查
- `http://127.0.0.1:8000/docs` → Swagger 接口文档
- 首次启动自动 `CREATE TABLE` 并 seed 4 条示例模板

---

## 四、前后端联调

1. `miniprogram/config/env.js`：`USE_MOCK = false`，`BASE_URL = 'http://127.0.0.1:8000/api'`
2. `miniprogram/project.config.json` 已设 `urlCheck: false`（开发不校验域名）
3. 重新编译前端，请求即转发到本地后端

> 真机预览需 HTTPS + 公众平台配置 `request` 合法域名；模拟器与本地直连不受限。
