# 9 - 开发运行指南

> 配套文档：本指南说明「知途 AI 旅行」小程序前端 + 后端的本地运行与联调方式。设计规范见 `docs/10`、`docs/8`，页面实现参考见 `outputs/`。

---

## 一、环境要求

| 层 | 要求 |
| :--- | :--- |
| 前端 | 微信开发者工具（稳定版）、支持游客/测试号预览 |
| 后端 | Python 3.13+、pip、可联网安装依赖 |
| 数据库 | 默认 SQLite（零配置）；生产可切 MySQL（`DATABASE_URL`） |
| 缓存 | Redis 可选（未配置时限流用内存兜底） |
| AI | 可选 LLM API Key；无 Key 时后端用内置示例生成器 |

---

## 二、前端运行（Mock 优先）

前端 `miniprogram/config/env.js` 关键开关：

```js
const env = {
  APP_NAME: '知途 AI 旅行',
  BASE_URL: 'http://192.168.10.8:8000',   // 注意末尾不带 /api，接口自带前缀
  MONETIZATION_ENABLED: false,           // 个人主体：关掉一切付费能力
  WX_APP_ID: 'wxf5fd654f184a0bb7',
  DAILY_PLAN_LIMIT: 3                    // 仅前端文案；真实限流在后端 quota_service
}
```

**运行前提：后端必须在线**（2026-10-23 起前端已无 mock 模式）

1. 先启动后端，确认 `http://127.0.0.1:8000/api/health` 返回 `{"status":"ok"}`
2. 微信开发者工具 → 导入项目 → 选 `miniprogram/`
3. AppID 填 `env.js` 里的 `WX_APP_ID`（真机跳转第三方小程序必须真实 AppID）
4. 「详情 → 本地设置」勾选「不校验合法域名」
5. 编译 → 模拟器/真机预览

城市列表在 `utils/cities.js`（产品数据），接口错误统一走 `utils/error.js`。

## 三、后端运行

```bash
cd server
python -m venv venv
venv\Scripts\pip install -r requirements.txt
cp .env.example .env
# 可选：填写 WX_APP_ID / LLM_API_KEY / DATABASE_URL
venv\Scripts\uvicorn app.main:app --port 8000
```

启动后：
- `http://127.0.0.1:8000/` → 返回 `{"code":0,"message":"知途 AI 旅行 API 运行中","data":null}`
- `http://127.0.0.1:8000/api/health` → `{"status":"ok"}`
- 首次启动自动 `CREATE TABLE`（8 张）并 seed 4 条示例模板

> `/docs` 与 `/openapi.json` 在 `app/main.py` 里被显式关闭（`docs_url=None` 等，上线安全加固）。本地要看 Swagger，临时把 `docs_url`/`redoc_url`/`openapi_url` 三个 `=None` 去掉即可，别提交。

## 三·五、知识索引与测试

```bash
# 建/重建 RAG 索引（没索引时问答会静默降级成关键词匹配，功能不报错但质量差）
venv\Scripts\python scripts\build_kb.py

# 跑测试：176 例，离线（临时 SQLite + 外部 API mock + 每用例独立 milvus-lite 临时库），实测约 33 秒
venv\Scripts\python -m pytest -q
```

`scripts/build_kb.py` 会打真实 HTTP（高德 POI + 百炼 embedding），需要 `.env` 里有 `GAODE_WEB_KEY`；`VISION_API_KEY` 同一把百炼 key 就能做 embedding，`EMBEDDING_API_*` 留空即可。测试不联网，二者的凭据要求不同。

## 四、前后端联调

1. `miniprogram/config/env.js`：`BASE_URL = 'http://127.0.0.1:8000'`（模拟器）或 `http://电脑局域网IP:8000`（真机）
2. `miniprogram/project.config.json` 已设 `urlCheck: false`（开发不校验域名）
3. 重新编译前端，请求即转发到本地后端

> 真机预览需 HTTPS + 公众平台配置 `request` 合法域名；模拟器与本地直连不受限。
