## 一、立项背景与行业现状

### 1.1 市场背景

国内短途周边游、城市轻旅行需求持续爆发，周末、节假日出游人群规模逐年上涨。当前游客规划行程存在明显痛点：旅游信息分散在小红书、抖音、地图、点评、OTA 多平台，景点、美食、交通、避坑等信息呈碎片化状态，用户手动整合攻略平均耗时 3 小时以上。

主流产品分为两类，均存在明显短板：

1. **OTA 平台**（携程、美团）：主打酒店、门票、车票预订，行程生成功能简陋，无个性化 AI 定制能力。
2. **通用 AI 工具 / 旅游笔记平台**：仅输出文字路线，无法联动订票、打车等出行服务，规划完成后仍需切换多个软件。

### 1.2 用户核心痛点

1. **旅游信息高度碎片化**：游玩点位、本地美食、交通路线、避坑提醒分散在多个平台，无统一信息载体，用户需要手动筛选、复制、拼凑完整行程，效率低下。
2. **行程创建方式单一**：市面工具仅支持文字输入生成路线，缺少现成城市模板、截图攻略导入、自定义拖拽编排能力。
3. **行程规划与出行消费服务割裂**：规划完路线后，预订酒店、打车、购买景区门票需要跳转不同 App，操作繁琐。
4. **缺少统一行程资产管理体系**：用户规划的路线散落在备忘录、截图中，无法统一存储、二次编辑、分享复用。
5. **旅途临时问题无即时咨询渠道**：出行途中想查询本地美食、景区注意事项、避雷建议，缺少随身旅游智能问答助手。

### 1.3 项目创新价值

本项目主打**全链路碎片化旅游信息整合**，依托大模型自动聚合游玩、餐饮、交通、预算全套信息，同时集成打车、酒店、门票等第三方服务快捷跳转入口，实现"需求输入 → AI 生成行程 → 配套服务预订"完整闭环；支持四种行程创建模式，搭配公共行程模板广场，兼顾新手快速规划与深度自定义需求。

## 三、项目整体功能架构

产品分为两大顶层 Tab：**【知途 AI 旅行（首页规划主页面）】**、**【随便问（旅游智能对话助手）】**；底部全局导航固定三栏：首页、我的行程、我的。

### 3.1 首页核心模块

- **模块 1 - 行程规划核心入口**：支持 AI 智能表单规划、一句话快规划、截图识行程、手动编排路线四种创建方式。
- **模块 2 - 快捷导航服务区**：顶部城市选择器，下方功能图标直达美团、携程等第三方服务。
- **模块 3 - 精选行程模板广场**：展示预制成熟城市短途行程卡片，支持"换一批"刷新、一键加载。

### 3.2 随便问 Tab

实时问答：查询城市美食避雷、景区开放时间、出行避坑、行李打包建议；配套工具：AI 自动生成出行行李清单、本地美食红黑榜。

### 3.3 我的行程

分类标签（使用中 / 全部行程），展示所有已保存行程，支持查看、编辑、删除、批量管理；行程详情支持 AI 对话式微调路线。

### 3.4 我的（个人中心）

用户基础信息、数据统计（累计规划行程数、解锁城市数）、功能菜单（收藏、发布、会员中心、客服、分享、系统设置）。

### 3.5 会员权限分层

| 权限项       | 免费用户                    | 付费会员                     |
| :----------- | :-------------------------- | :--------------------------- |
| AI 行程生成  | 每日 3 次                   | 不限次数                     |
| 行程存储     | 临时缓存，关闭页面丢失       | 永久云端存储                  |
| 小众深度路线 | 不可用                      | 解锁                          |
| 截图识行程   | 不可用                      | 解锁                          |
| 广告         | 有                          | 无                           |
| 精品模板     | 不可用                      | 优先使用                      |

## 四、完整用户业务流程

```
用户进入小程序 → 微信一键授权登录
    ├── 路径 A：点击【开始规划行程】→ 选择创建方式 → AI 生成行程
    └── 路径 B：选用首页精选行程模板 → 加载后自定义修改
            ↓
AI 输出结构化分日行程 → 不满意可对话微调
            ↓
行程保存至【我的行程】→ 随时二次编辑
            ↓
行程内景点/餐厅需要预订 → 快捷导航跳转第三方小程序
            ↓
旅游疑问 → 切换至【随便问】对话助手
            ↓
优质自制行程 → 发布至模板广场供他人使用
```

## 九、项目优势与创新点

1. **多模式行程创建**：同时提供表单、一句话、截图导入、手动拖拽四种规划方式。
2. **旅游全链路一体化闭环**：业内少有将 AI 行程规划与打车、酒店、票务预订整合在同一小程序。
3. **大众 + 小众双路线生成**：满足网红打卡与避人流深度游两类需求。
4. **轻量化低成本落地**：无需自建地图、票务、酒店系统，依靠跨应用跳转实现配套服务。
5. **完整行程资产管理制度**：统一存储、收藏、分享、复用行程模板。
