## 一、尺寸换算（最重要）

- 设计稿基准：**375pt（iPhone 逻辑像素）**。
- 小程序使用 `rpx`：屏幕固定 750rpx，即 **1px 设计 = 2rpx**。
- 换算口诀：设计里所有 px 值 ×2 即得 rpx（如 16px 间距 → `32rpx`，48px 按钮高 → `96rpx`）。
- 字号同理 ×2（28px → `56rpx`）。但小程序 `rpx` 在超大屏会放大，正文建议用 `rpx`、固定装饰用 `px` 也可。
- 状态栏高度设计稿 62px（含安全区），代码中建议用 `wx.getWindowInfo().statusBarHeight` 动态取，避免写死。

## 四、圆角与间距

**圆角**
- Logo：24rpx（96px 圆角 24）
- 卡片 / Banner / 弹窗：16rpx（大卡）、12rpx（标准卡 / 支付按钮 / 弹窗）
- 次级小卡 / 图标按钮：8rpx
- 标签 / 复选框：4rpx
- 圆形徽标：10rpx（20px 圆）
- 全圆角按钮：高度一半（48px 按钮 → 圆角 24rpx）

**间距（基础单位 8rpx 递进）**
- 页面左右安全边距：32rpx（设计 16px）
- 卡片内边距：24~32rpx
- 列表项间距：12rpx（设计 6~8px 视场景）
- 区块间距：16~24rpx

## 八、上线前设计侧注意点（对接开发必读）

1. **个人主体限制**：个人小程序无微信支付、无 OCR / 手机号等接口权限。本项目有会员付费 + 分销，必须用**企业/个体户**主体，否则支付与核心能力跑不通。
2. **HTTPS 域名白名单**：FastAPI 后端域名须 HTTPS，并在公众平台配置 `request` / `uploadFile` / `downloadFile` 合法域名，否则真机请求被拦。
3. **状态栏与安全区**：设计稿状态栏为示意，代码用 `wx.getWindowInfo()` 动态取，底部留 `env(safe-area-inset-bottom)` 适配 iPhone 底部条。
4. **图标资源导出**：49 个 SVG 组件在画布顶层，开发前请统一导出（建议 2x PNG 或转 iconfont），避免逐页截图取图。
5. **rpx 一致性**：所有间距/字号/圆角按"×2"规则换算，不要把设计稿 px 原样当 rpx，否则在大屏会偏小。
6. **授权弹窗状态**：WF-12 已在同一画布内叠加"授权弹窗"覆盖层（半透明遮罩 + 底部白卡），开发时建议做成全局 `modal` 组件，登录拦截统一调用。
