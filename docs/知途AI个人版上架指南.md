## 二、你在本机需要做的 5 步（必须本人操作，我登不了你的微信账号）

### 第 1 步：公众平台填「用户隐私保护指引」
1. 登录 https://mp.weixin.qq.com → 你要确认账号主体是**个人**
2. 左侧「设置 → 服务内容（或 用户隐私保护指引）」→ 点击「配置」
3. 勾选你实际用到的：微信昵称、微信头像、位置信息（行程导航）
4. 填写隐私政策访问地址：把你托管的隐私政策网址填进去
   - 本仓库已提供 `docs/privacy-policy.html`，需托管到 **HTTPS** 网址
   - 快速托管：用你的腾讯云服务器（域名+SSL 就绪后）放这个文件；或临时用支持 HTTPS 的静态页服务
   - ⚠️ 微信要求隐私政策 URL 必须是 HTTPS，纯 IP / HTTP 不行

### 第 2 步：设置服务类目
- 「设置 → 基本设置 → 服务类目」→ 添加类目
- 选 **「工具 → 效率办公」**（或「生活服务」类下合适的免费工具类目）
- **不要选「旅游」**（旅游要《旅行社业务经营许可证》，个人根本办不下）

### 第 3 步：开发者工具上传代码
1. 打开微信开发者工具 → 导入项目目录 `miniprogram/`
2. AppID 填你的 `wxf5fd654f184a0bb7`
3. 确认 `config/env.js`：`USE_MOCK:true`、`MONETIZATION_ENABLED:false`
4. 点右上「上传」→ 填版本号（如 `1.0.0`）和备注 → 上传成功

### 第 4 步：提交审核
1. 回到 mp.weixin.qq.com → 「管理 → 版本管理」
2. 在「开发版本」找到刚上传的版本 → 点「提交审核」
3. 按引导填：功能页面（选首页）、类目（工具）、是否含付费（选**否**）
4. 提交 → 等待微信审核（通常 1–7 个工作日）

### 第 5 步：审核通过 → 发布
- 审核通过后点「发布」即可对公众开放
- 个人主体无需微信认证也可发布免费工具（认证 300 元非强制，但建议后续办理提升信任）

## 三、让上线版「真能用 AI」（可选，需域名）
当前 `USE_MOCK=true` 上线后是**示例数据**演示版。要变成真 AI：
1. 买域名 → ICP 备案（腾讯云备案约 1–3 天）→ 部署 SSL
2. 后端部署到服务器 `https://你的域名`（Docker 方案见 `docker-compose.yml`）
3. 改 `config/env.js`：`USE_MOCK:false`、`BASE_URL:'https://你的域名'`
4. mp 后台「开发设置 → 服务器域名 → request 合法域名」添加 `https://你的域名`
5. 重新上传 + 提交审核

> 没有域名前，先用 `USE_MOCK=true` 提交审核拿「已发布」状态；拿到域名后再切真后端二次提交即可。
